# Sumidoku website

The Sumidoku project site and documentation hub.

Built with [Nimbus](https://nimbus-docs.com) (Astro). The landing page is
`src/pages/index.astro`; the docs live under `src/content/docs/docs/` and are
authored as MDX. Agent-facing outputs (per-page markdown, `/llms.txt`,
`/llms-full.txt`, JSON-LD, sitemap) are generated by Nimbus on every build.

## Develop

```sh
npm install
npm run dev        # dev server with hot reload
npm run build      # production build in dist/
npm run typecheck
npm run lint:docs  # prose + MDX lint
```

Node 22 LTS is recommended (matches CI).

## Deploy

Cloudflare Workers Builds: pushes to `main` build the site
(`npm ci && npm run build`) and deploy the `sumidoku` Worker (static assets
from `dist/`). Add the custom domain in `wrangler.jsonc` when it is ready.
To deploy a local build manually:

```sh
npm run deploy     # wrangler deploy
```

## Content notes

- Screenshots in `public/img/shots/` are copied from the main repository's
  `docs/images/`; retake them when the web UI changes meaningfully.
- The logo in `public/img/logo.svg` comes from `webui/public/icon.svg` in the
  main repository.
- Docs pages mirror the guides in the main repository's `docs/` directory;
  when a guide changes upstream, update the matching MDX page here.
